🏅 Olympic Medal Analysis Web Application

📌 Overview
->The Olympic Medal Analysis Web App is an interactive data analysis tool that provides detailed insights into Olympic medal statistics. Users can explore medal-winning countries, athletes, and events with powerful search and filter options.
The app also includes data visualizations, heatmaps, and charts for better understanding of performance trends across different years and competitions.

🔗 Live Demo: https://bit.ly/OlympicMedalAnalysis

🚀 Features
-> Search & Filter – Find specific athletes, countries, or events.
-> Data Visualization – Heatmaps, bar charts, and trend plots for medal distribution.
-> Athlete & Country Insights – View medal counts, event details, and competitor information.
-> Machine Learning Integration – Applied ML techniques for data analysis and insights.
-> Cloud Deployment – Hosted on Streamlit Cloud for easy access.


📂 Dataset
-> Source: Kaggle - https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results
Contains historical Olympic medal data, including:
Athlete name
Country (NOC)
Event and sport
Year and season (Summer/Winter)
Medal type (Gold/Silver/Bronze)

🛠️ Tech Stack
-> Python
-> pandas – Data manipulation and preprocessing
-> Scikit-Learn – ML algorithms for analysis
-> Matplotlib/Pyplot – Charting and plotting
-> Seaborn – Heatmap visualization
-> Streamlit – Web app development and deployment


📊 Machine Learning & Analysis
-> Exploratory Data Analysis (EDA) for identifying trends and patterns.
-> Feature Engineering to improve dataset usability.
-> Seaborn library for visualizing performance comparisons.



📦 Installation & Usage
(1). Clone the Repository:
      git clone https://github.com/darshit111/Olympic-Medal-Analysis.git
      cd Olympic-Medal-Analysis

(2). Install Dependencies:
      pip install -r requirements.txt

(3). Run the App
      streamlit run app.py

(4). Access in Browser
      Go to http://localhost:8501
